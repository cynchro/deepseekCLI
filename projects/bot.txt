Eres un ingeniero senior especializado en sistemas de IA, RAG, procesamiento de audio y despliegue con Docker. Tu objetivo es diseñar e implementar un sistema completo que permita:

- Recibir un audio como input
- Transcribirlo a texto
- Buscar información en documentos previamente ingestados
- Generar una respuesta basada SOLO en esa información (sin alucinaciones)
- Convertir la respuesta en audio
- Devolver ese audio como output

El sistema debe ser 100% funcional, eficiente y ejecutable en una máquina local sin dependencias instaladas, usando Docker.

# REQUISITOS DEL SISTEMA

## 1. Arquitectura general

Pipeline obligatorio:

audio → texto → embeddings → búsqueda → contexto → LLM → texto → TTS → audio

---

## 2. Tecnologías obligatorias

- STT: faster-whisper
- Embeddings: sentence-transformers
- Vector DB: FAISS
- LLM: Groq API
- TTS: Piper

---

## 3. Docker (CRÍTICO)

Debes:

- Crear un Dockerfile completo
- Crear un docker-compose.yml
- Asegurar que TODO funcione dentro del contenedor
- No depender de nada instalado en el host excepto Docker

El contenedor debe:

- Instalar todas las dependencias necesarias
- Descargar modelos necesarios (o explicar cómo montarlos)
- Exponer un comando simple para ejecutar el flujo completo

---

## 4. Persistencia

- El índice FAISS debe persistirse (volumen Docker)
- Los documentos ingestados deben persistirse
- Evitar recomputar embeddings en cada ejecución

---

## 5. Sistema RAG

Implementar:

- Ingesta de documentos (PDF/TXT)
- Chunking (500–1000 tokens)
- Embeddings
- Indexación en FAISS

En runtime:

- Top-k retrieval (3–5)
- Construcción de contexto

---

## 6. Control de alucinaciones

El sistema DEBE:

- Responder SOLO con el contexto
- NO inventar información
- Si no encuentra respuesta → responder:
  "No tengo esa información en los documentos proporcionados"

## 8. TTS

- Modelo en español
